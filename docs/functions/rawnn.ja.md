# `rawnn()`：列番号と変数名の一覧表示

## 1. 概要

`rawnn()` は、データフレームに含まれる変数名を列番号とともにコンソールへ表示する関数です。

質問紙調査のデータには、回答者ID、基本属性、質問項目、尺度得点など、多数の変数が含まれることがあります。`rawnn()`を使うと、データフレーム内の列番号と変数名の対応を確認できます。

例えば、次のような文字ベクトルがコンソールに表示されます。

```text
[1] "1: ID" "2: Age" "3: Gender" "4: Q1" "5: Q2" "6: Q3" "7: Q4"
```

`rawnn()`は回答品質を評価する統計指標ではありません。データ構造を確認し、分析対象の変数を適切に指定するための補助関数です。

## 2. 基本的な使用方法

関数の構文は次のとおりです。

```r
rawnn(dataframe)
```

| 引数 | 説明 |
|---|---|
| `dataframe` | 列番号と変数名を表示するデータフレーム |

使用例：

```r
library(Satisficing)

df <- data.frame(
  ID = 1:3,
  Age = c(25, 32, 41),
  Q1 = c(3, 4, 2),
  Q2 = c(4, 4, 3),
  Q3 = c(3, 5, 2)
)

rawnn(df)
```

列番号はRの標準的なインデックスに従い、1から始まります。データフレーム内の列順に表示され、変数名をアルファベット順に並べ替えることはありません。

## 3. 分析対象の列を確認する

多数の変数を含むデータで、分析対象項目の位置を確認する用途があります。例えば、Q1からQ5が4列目から8列目にある場合、列番号を使って次のように選択できます。

```r
items <- df[, 4:8]
```

変数名を使って選択することもできます。

```r
items <- df[, paste0("Q", 1:5)]
```

列番号による指定は、列順が変わると別の変数を参照する可能性があります。再現性を重視する分析コードでは、可能な限り変数名で指定してください。列番号を使う場合は、データの列構成が想定どおりであることを確認します。

## 4. ほかの関数との組合せ

`rawnn()`は、`Satisficing`のほかの関数に渡す項目を確認する際にも使えます。`longstring()`は入力列を項目の順序として扱うため、提示順に項目を選ぶことが重要です。

```r
rawnn(df)
longstring(df[, 4:8])
```

`stline()`では列名を指定できます。

```r
stline(
  df,
  columns = c("Q1", "Q2", "Q3", "Q4", "Q5")
)
```

このように、識別番号や基本属性などを誤って分析対象に含めることを防ぐための確認に利用できます。

## 5. `names()`および`colnames()`との違い

Rには、データフレームの列名を取得する`names()`や`colnames()`があります。例えば、`names(df)`は次のような文字ベクトルを返します。

```text
[1] "ID" "Age" "Q1" "Q2" "Q3"
```

一方、`rawnn()`は各列の番号と変数名を組み合わせて表示します。

| 関数 | 主な用途 | 返り値 |
|---|---|---|
| `names()` | 変数名の取得 | 文字ベクトル |
| `colnames()` | 列名の取得 | 文字ベクトル |
| `rawnn()` | 列番号と変数名の対応を表示 | `invisible(NULL)` |

列名をプログラム内で再利用する場合は`names()`または`colnames()`を使います。`rawnn()`はコンソール上で確認するための関数です。

## 6. 返り値と処理上の特徴

`rawnn()`は列番号と変数名を表示し、公式ヘルプに定義された返り値は`invisible(NULL)`です。

```r
result <- rawnn(df)
```

この場合も一覧は表示されますが、`result`には`NULL`が代入されます。列名をコード内で利用する場合は`names()`または`colnames()`を使用してください。

`rawnn()`はデータフレームを変更しません。列の追加、削除、並べ替えは行いません。また、引数がデータフレームでない場合はエラーになります。

## 7. 利用上の注意点

### 7.1 列番号はデータフレームの構造に依存する

表示される列番号は、関数を実行した時点の列位置です。列の追加、削除、並べ替えにより番号は変わるため、列番号を使うコードでは列構成を確認してください。

### 7.2 変数の意味は判定しない

`rawnn()`はデータフレームに保存された列名を表示するだけです。尺度や構成概念、逆転項目かどうか、回答カテゴリーなどは判定しません。必要な情報は調査票、コードブック、変数定義書で確認してください。

### 7.3 データの値は表示しない

表示されるのは列番号と変数名だけです。データ型、欠測数、回答分布などを調べる場合は、Rの`str()`、`summary()`、`head()`などを使用します。

## 8. まとめ

`rawnn()`は、データフレーム内の列番号と変数名を対応づけて表示する補助関数です。多数の項目を含むデータを扱う際、分析対象の列を確認するのに役立ちます。

回答品質を評価する関数ではないため、列構造を確認した後、分析目的に合った変数を選択してください。
