# `longstring()`：同一回答の最大連続数と平均連続長

## 1. 概要

`longstring()` は、質問紙調査において、同じ回答カテゴリーが連続して選択された項目数を測定する関数です。

質問紙調査では、回答者が複数の質問に対して同じ選択肢を繰り返し選択することがあります。このような回答パターンはストレートライン回答（straightlining）と呼ばれ、低努力回答（insufficient effort responding; IER）や不注意回答（careless responding）の兆候として研究されています。

`longstring()` は、各回答者について次の2指標を計算できます。

- **Maximum Longstring（最大連続同一回答数）**：同じ回答値が連続した最長区間の項目数。
- **Average Longstring（平均連続同一回答長）**：同じ回答値が続いた各区間の長さの平均値。

例えば、次の12項目の回答を考えます。

```text
項目    01 02 03 04 05 06 07 08 09 10 11 12
回答     3  3  3  3  4  4  4  3  3  3  3  5
         └── 4 ──┘ └─3─┘ └── 4 ──┘ 1
```

この回答は、長さ4、3、4、1の4区間に分けられます。

したがって、

\[
\text{Maximum Longstring}=4
\]

\[
\text{Average Longstring}=\frac{4+3+4+1}{4}=3
\]

となります。

Maximum Longstringは最も長い連続回答区間を評価し、Average Longstringは回答全体にわたって、同じ値がどの程度続くかを評価します。

## 2. 計算方法

回答者 \(i\) の項目への回答を、提示順に

\[
\mathbf{x}_i=(x_{i1},x_{i2},\ldots,x_{ip})
\]

とします。

ここで \(p\) は分析対象の項目数です。

隣接する2項目の回答値が同じ場合には同一の連続区間に属し、異なる場合には新しい区間が始まります。

その結果、回答者 \(i\) の回答列が \(K_i\) 個の連続区間に分割され、各区間の長さが

\[
L_{i1},L_{i2},\ldots,L_{iK_i}
\]

として得られるものとします。

### 2.1 Maximum Longstring

最大連続同一回答数は次のように定義されます。

\[
LS_{\max,i}=\max_{1\leq k\leq K_i}L_{ik}
\]

例えば、回答列が

```text
3 3 3 4 4 3 3 3 3 5
```

であれば、連続区間の長さは3、2、4、1です。

したがって、Maximum Longstringは4になります。

すべての回答が同じ場合には、Maximum Longstringは項目数 \(p\) と一致します。

### 2.2 Average Longstring

平均連続同一回答長は、すべての連続区間の長さの平均です。

\[
LS_{\mathrm{avg},i}=
\frac{1}{K_i}\sum_{k=1}^{K_i}L_{ik}
\]

欠測のない回答列では、各区間の長さの合計が項目数 \(p\) になるため、

\[
LS_{\mathrm{avg},i}=\frac{p}{K_i}
\]

とも表せます。

例えば、10項目の回答が4区間に分かれていれば、Average Longstringは2.5です。

つまり、Average Longstringは連続区間の数が少ないほど大きくなります。

## 3. 基本的な使用方法

関数の構文は次のとおりです。

```r
longstring(x, avg = FALSE)
```

| 引数 | 説明 |
|---|---|
| `x` | 回答者を行、項目を列とする行列またはデータフレーム |
| `avg` | 平均連続同一回答長を併せて計算するかを指定する論理値 |

デフォルトの `avg = FALSE` では、Maximum Longstringのみが計算され、回答者ごとの数値ベクトルが返されます。

`avg = TRUE` の場合は、次の2列を含むデータフレームが返されます。

| 列名 | 内容 |
|---|---|
| `longstr` | Maximum Longstring |
| `avgstr` | Average Longstring |

### 3.1 Maximum Longstringの計算

```r
library(Satisficing)

df <- data.frame(
  Q1 = c(3, 4, 2),
  Q2 = c(3, 4, 3),
  Q3 = c(3, 4, 2),
  Q4 = c(4, 4, 3),
  Q5 = c(4, 2, 2),
  Q6 = c(4, 2, 3)
)

longstring(df)
```

このデータでは、

- 回答者1：`3, 3, 3, 4, 4, 4`
- 回答者2：`4, 4, 4, 4, 2, 2`
- 回答者3：`2, 3, 2, 3, 2, 3`

となっています。

したがって、計算結果は次のとおりです。

```text
[1] 3 4 1
```

### 3.2 Average Longstringの計算

```r
longstring(df, avg = TRUE)
```

連続区間の長さから計算すると、次の値になります。

| 回答者 | 連続区間の長さ | longstr | avgstr |
|---|---|---:|---:|
| 1 | 3, 3 | 3 | 3.0 |
| 2 | 4, 2 | 4 | 3.0 |
| 3 | 1, 1, 1, 1, 1, 1 | 1 | 1.0 |

このように、最大連続数が異なっていても、平均連続長が同じになる場合があります。

## 4. 項目の順序が持つ意味

`longstring()` の重要な特徴は、**項目の並び順によって値が変化する**ことです。

例えば、次の2つの回答列を考えます。

```text
A: 3 3 3 3 4 4 4 4
B: 3 4 3 4 3 4 3 4
```

いずれも回答3と4が4回ずつ選択されています。

しかし、

| 回答列 | Maximum Longstring | Average Longstring |
|---|---:|---:|
| A | 4 | 4 |
| B | 1 | 1 |

となります。

この違いは、Longstringが回答カテゴリーの使用頻度ではなく、回答の連続性を評価していることを示しています。

したがって、Longstringの計算には、原則として**回答者に質問が提示された順序**を使用してください。

データフレーム内の列の順番が実際の提示順序と異なる場合には、正しい順番に並べ直してから計算する必要があります。

また、逆転項目がある尺度では、回答値を逆転処理してから計算すると、実際に同じ選択肢を連続して選んだという回答行動を正確に捉えられないことがあります。

回答行動としてのストレートラインを評価する目的では、逆転処理前の回答値を使用するのが適切です。

## 5. `stline()` との違い

`Satisficing` には、指定された項目の回答がすべて同一かどうかを判定する `stline()` も実装されています。

両関数は関連していますが、測定対象が異なります。

| 指標 | `stline()` | `longstring()` |
|---|---|---|
| 主な目的 | 全体的な完全同一回答の検出 | 同一回答の連続区間の長さ |
| 出力 | 0、1、NA | 連続数 |
| 項目の並び順 | 依存しない | 依存する |
| 途中で回答値が変化する場合 | 0 | 最長区間を計算 |
| 部分的なストレートライン | 直接検出しない | 検出できる |

例えば、

```text
3 3 3 3 3 4 4 4 4 4
```

の場合、`stline()` は0を返しますが、`longstring()` は5を返します。

全体としては完全同一回答ではなくても、一部分に連続した同一回答が存在することを捉えられます。

## 6. 欠測値の取り扱い

欠測値を含む回答列では、連続区間の定義が問題になります。

例えば、

```text
3 3 NA 3 3
```

という回答では、欠測値を区間の切れ目とみなす場合、観測された3の連続区間は長さ2と2になります。

一方、欠測値を除去してから計算した場合には、

```text
3 3 3 3
```

となり、Maximum Longstringは4になります。

両者では測定しているものが異なります。

`Satisficing` v0.2.0の `longstring()` は `careless` 1.2.2から移植された関数です。公式ヘルプでは欠測値を含む場合の細かな計算規則は明示されていませんが、実装では次のように処理します。

実装では、欠測値を削除せずにRの `rle()` で連続区間を計算します。Rの `rle()` では、`NA` は直前の値と等しくないものとして扱われ、連続する `NA` 同士も別々の区間になります。

したがって、`3, 3, NA, 3, 3` の区間長は `2, 1, 1, 2` です。この場合、Maximum Longstringは2、Average Longstringは1.5になります。欠測値を自動的に除去してから計算する挙動ではありません。

完全回答者に限定した分析では、この問題を回避できますが、その場合も完全回答者に限定することによる標本選択の影響には注意が必要です。

## 7. 結果の解釈

Maximum Longstringが大きい場合、同じ回答カテゴリーが長く連続して選択されていることを意味します。

Average Longstringが大きい場合は、回答全体を通して、同じ回答カテゴリーが継続しやすいことを意味します。

ただし、**Longstringの値が大きいことは、それだけで不注意回答を意味するものではありません。**

同じ回答が続く理由には、認知的努力の省略以外にも、質問項目の類似性、回答者の特性、選択肢の分布、項目の配置などが考えられます。

また、同一回答が長く続く確率は、項目数や回答カテゴリー数に依存します。

例えば、5項目の質問群でLongstringが5となることと、50項目の質問群でLongstringが5となることは、同じ測定上の意味を持ちません。

したがって、異なる質問群や調査の間でLongstringを比較する場合には、項目数や質問内容を考慮する必要があります。

## 8. 判定基準について

`longstring()` は連続同一回答の長さを計算する関数であり、回答者を不注意回答者と判定する固定の閾値を提供するものではありません。

例えば、Maximum Longstringが10以上であることを問題とする基準を設定したとしても、その基準がすべての質問紙に適用できるわけではありません。

回答の偶然的な一致確率は、質問項目数、回答カテゴリー数、項目間相関、回答分布などによって変化するためです。

そのため、Longstringによる回答品質の評価では、調査設計を考慮して判定基準を検討する必要があります。

また、Maximum Longstringは最長の1区間のみに基づくため、回答全体における回答パターンの特徴を十分に反映しない場合があります。

その点で、Maximum LongstringとAverage Longstringを併用することには意義があります。

## 9. 研究での利用方法

Longstringは、回答品質を評価する複数の指標の一つとして利用できます。

例えば、Meade and Craig (2012) は、不注意回答の検出に関する複数の方法を検討しており、単一の指標のみに依存した判断には限界があることを示しています。

Longstringが大きい回答者については、個人内回答変動（IRV）、項目間の一貫性、論理的に矛盾する回答の有無など、ほかの情報と併せて検討することが考えられます。

研究論文では、使用した項目数、項目の提示順序、MaximumとAverageのいずれを使用したか、欠測値の処理方法、判定基準を明記することで、分析手続きの再現性を高められます。

また、回答者を除外する場合には、除外人数および除外前後の分析結果を報告することが望まれます。
