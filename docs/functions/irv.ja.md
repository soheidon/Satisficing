# `irv()`：個人内回答変動（Intra-individual Response Variability）

## 1. 概要

`irv()`は、各回答者の回答値のばらつきを標準偏差で表す関数です。この指標は個人内回答変動（Intra-individual Response Variability; IRV）と呼ばれ、複数項目にどの程度異なる回答カテゴリーを使用したかを記述します。

すべて「3」と回答した人と、「1」「3」「5」を使い分けた人では回答値の変動が異なります。Dunn et al. (2018)はIRVを低努力回答（insufficient effort responding; IER）の検討に用いました。IRVが小さい場合は回答値の変化が乏しいパターン、大きい場合は回答値が広く変動するパターンを示します。後者はランダム回答の候補を調べる手がかりとして用いられることがあります。

ただし、回答値の変動は回答者の実際の特性や項目内容にも左右されます。IRVの大小だけで不注意回答と判定することはできません。

## 2. 計算方法

IRVは、各回答者の指定項目に対する**標本標準偏差**です。回答者\(i\)の有効回答を\(x_{ij}\)、有効回答数を\(n_i\)、有効回答の平均を\(\bar{x}_i\)とすると、

\[
IRV_i=\sqrt{\frac{1}{n_i-1}\sum_{j=1}^{n_i}(x_{ij}-\bar{x}_i)^2}.
\]

分母は\(n_i-1\)です。実装では各回答者の行にRの`sd()`を適用します。

| 回答者 | Q1 | Q2 | Q3 | Q4 | Q5 | IRV |
|---|---:|---:|---:|---:|---:|---:|
| A | 3 | 3 | 3 | 3 | 3 | 0.000 |
| B | 3 | 3 | 4 | 3 | 4 | 0.548 |
| C | 1 | 2 | 3 | 4 | 5 | 1.581 |
| D | 1 | 5 | 1 | 5 | 3 | 2.000 |

Aは全項目で同じ値なのでIRVは0です。Bは3と4を使い、CとDはより広い範囲の回答値を含むためIRVが大きくなります。CやDが不注意回答をしたと結論づけるものではありません。

## 3. 基本的な使用方法

```r
irv(x, na.rm = TRUE, split = FALSE, num.split = 3)
```

| 引数 | 説明 |
|---|---|
| `x` | 回答者を行、項目を列とする行列またはデータフレーム |
| `na.rm` | 標準偏差を計算するときに欠測値を除くかどうか。既定値は`TRUE` |
| `split` | 全項目のIRVに加えて、項目群ごとのIRVも計算するかどうか |
| `num.split` | 項目群の数。既定値は3 |

### 3.1 全項目のIRV

```r
library(Satisficing)

df <- data.frame(
  Q1 = c(3, 3, 1, 1),
  Q2 = c(3, 3, 2, 5),
  Q3 = c(3, 4, 3, 1),
  Q4 = c(3, 3, 4, 5),
  Q5 = c(3, 4, 5, 3)
)

irv(df)
```

出力は回答者ごとの数値ベクトルです。

```text
[1] 0.0000000 0.5477226 1.5811388 2.0000000
```

元のデータフレームにIRVを追加するには、計算対象項目だけを渡して結果を代入します。

```r
df$irv <- irv(df)
```

IDや属性変数を誤って含めると、IRVは意図した項目回答のばらつきを表さなくなります。

## 4. 項目群に分割したIRV

`split = TRUE`では、全項目のIRVに加えて、列位置に基づいて分けた各項目群のIRVを計算します。質問紙の一部で回答変動が変化するパターンを確認するのに使えます。

```r
result <- irv(careless_dataset, split = TRUE, num.split = 4)
head(result)
```

返り値は`irvTotal`と、各部分に対応する`irv1`、`irv2`などの列を持つデータフレームです。例えば前半と後半を比べるには、次のようにできます。

```r
boxplot(
  result$irv1,
  result$irv4,
  names = c("First", "Last"),
  ylab = "IRV"
)
```

実装では、列番号の並びに`cut(..., breaks = num.split)`を適用して項目群を作ります。項目数が分割数で割り切れない場合、各部分の項目数は同じにならないことがあります。各部分のIRVはその部分だけから計算され、`irvTotal`は分割IRVの平均ではなく、全項目の標準偏差です。

分割結果は列順に依存するため、質問紙の提示順を調べたい場合は、列を実際の提示順に並べてください。部分間の差は、回答品質の変化だけでなく項目内容、回答カテゴリーの分布、尺度構成の違いでも生じます。

## 5. 欠測値の取り扱い

既定値の`na.rm = TRUE`では、欠測値を除いた有効回答から標準偏差を計算します。例えば`3, 3, NA, 4, 4`の場合、`sd(c(3, 3, 4, 4))`を計算し、約0.577となります。

`na.rm = FALSE`では、欠測値を含む回答者のIRVは`NA`になります。有効回答が1つ以下の場合も標準偏差を計算できず、結果は`NA`です。

| 回答パターン | `na.rm = TRUE` | `na.rm = FALSE` |
|---|---:|---:|
| `3, 3, 3, 3` | 0 | 0 |
| `3, 3, 4, 4` | 約0.577 | 約0.577 |
| `3, 3, NA, 4` | 約0.577 | NA |
| `3, NA, NA, NA` | NA | NA |
| `NA, NA, NA, NA` | NA | NA |

欠測を除く設定では、回答者ごとに有効項目数が異なる場合があります。欠測が多いデータでは、有効回答数も併せて確認してください。

## 6. IRVが小さい場合

小さなIRVは、回答値の変化が乏しいことを示します。例えば、`3 3 3 3 3 3 3 3`のIRVは0です。`3 3 3 4 3 3 3 4`のように、主に同じ値を選ぶ場合もIRVは小さくなります。

Dunn et al. (2018)は、低いIRVを過度に一貫した回答やストレートライン回答を調べる手がかりとして扱っています。ただし、同じ構成概念を測る似た項目が続けば、注意深い回答でもIRVが小さくなることがあります。低IRVのみを根拠に回答者を除外しないでください。

## 7. IRVが大きい場合

大きなIRVは、回答値が広い範囲に及ぶことを示します。例えば`1 5 1 5 1 5 1 5`は大きなIRVになります。

Marjanovic et al. (2015)は、ランダム回答者と注意深い回答者を区別するため、項目間標準偏差（Inter-item Standard Deviation; ISD）を検討し、ランダム回答者のISDが大きい傾向を報告しました。ただし、その研究では下位尺度ごとにISDを計算し、複数の下位尺度の値を集約する方法も用いています。複数尺度の項目を一括した回答者内標準偏差を計算する`irv()`と、研究で用いられたISDの集約値を同一の指標として扱わないでください。

**高IRVはランダム回答と同義ではありません。** 異なる内容の項目に対して異なる態度を持つ回答者も、高いIRVを示すことがあります。またIRVは項目順序に依存しません。`1 1 5 5`と`1 5 1 5`は回答値の分布が同じため、IRVも同じです。連続長や回答値の切り替わり方は`longstring()`など別の指標で評価します。

## 8. `longstring()`との違い

| 比較項目 | `irv()` | `longstring()` |
|---|---|---|
| 測定対象 | 回答値のばらつき | 同じ回答が続く最長・平均区間長 |
| 計算方法 | 標準偏差 | 連続区間の長さ |
| 項目順序への依存 | なし | あり |
| 全項目が同じ回答 | IRV = 0 | Longstring = 項目数 |
| 分割計算 | `split = TRUE` | 対象列を選択して別途計算 |

例えば`3 3 3 3 4 4 4 4`と`3 4 3 4 3 4 3 4`は各回答値の頻度が同じなのでIRVも同じですが、Maximum Longstringはそれぞれ4と1です。両指標を併用すると、回答値のばらつきと並びの連続性を区別して確認できます。

## 9. 判定基準と利用上の注意

`irv()`は標準偏差を計算しますが、低努力回答を判定する固定の閾値は設けていません。解釈には回答カテゴリーの数値範囲、項目間相関、質問内容、尺度構成、有効回答数、分割時の項目群などが関係します。

IRVは回答カテゴリーに割り当てられた数値間の距離を使います。数値間隔が実質的な意味を持たない場合や、異なる尺度の項目を混在させる場合には、結果を慎重に解釈してください。逆転項目についても、回答行動の変動を測るのか、得点化後の値の変動を測るのかを明確にしてください。

## 10. 研究での利用

IRVは回答品質を検討する複数の手がかりの一つです。Dunn et al. (2018)は低IRVを含むIER指標を検討し、Marjanovic et al. (2015)は高い項目間変動を利用したランダム回答の識別を検討しています。低IRVと高IRVは異なる回答パターンへの着目であり、研究ではどちらをどの根拠で評価するかを明示してください。

報告時には、分析した項目群、項目順、分割の有無、欠測処理、判定基準を記載します。回答者を除外する場合は、除外人数と除外前後の結果も報告してください。
