# `matching()`：論理条件に基づく回答の検出

## 1. 概要

`matching()` は、データフレームの各行について、利用者が指定した論理条件を評価し、その条件に一致するかどうかを判定する関数です。

質問紙調査では、個々の回答値だけでなく、複数の項目の組合せから回答の特徴や矛盾を検討したい場合があります。例えば、ある経験が「ない」と回答しているにもかかわらず、その経験の頻度を「週に数回」と回答しているケースや、特定の設問間で論理的に両立しない回答が記録されているケースなどです。

`matching()` は、このような条件をRの論理式として記述し、該当する回答者を抽出するための補助的な機能を提供します。

ただし、この関数自体が回答の矛盾や不注意回答を自動的に発見するわけではありません。**何を一致条件とみなすかは利用者が定義する**必要があります。したがって、回答品質の評価だけでなく、対象者の抽出、データの点検、特定の回答パターンの分類などにも利用できます。

## 2. 判定方法

回答者 (i) について、指定された論理条件を (C_i) とします。

`matching()` は、この条件を評価し、次の整数値を返します。

結果は、条件が `TRUE` のとき `1`、`FALSE` のとき `0`、`NA` のとき `NA` です。

ここで、`TRUE` は条件を満たすこと、`FALSE` は条件を満たさないこと、`NA` は条件の評価結果が欠測・不定であることを意味します。

例えば、2項目について次の条件を指定したとします。

```
Q1 == 1 & Q2 >= 3
```

この条件は、Q1が1であり、かつQ2が3以上の場合に成立します。

| 回答者 | Q1 | Q2 | 判定 |
| --- | -- | -- | -- |
| A   | 1  | 4  | 1  |
| B   | 1  | 2  | 0  |
| C   | 2  | 4  | 0  |
| D   | 1  | NA | NA |
| E   | 2  | NA | 0  |

回答者DではQ1の条件は成立していますが、Q2の値が欠測しているため、全体の条件は `NA` になります。

一方、回答者EではQ1の条件が成立しないため、Q2が欠測していても全体の条件は `FALSE` となり、0が返されます。

これはRの論理演算における3値論理に従った挙動です。

## 3. 基本的な使用方法

関数の構文は次のとおりです。

```
matching(
  data,
  condition,
  result_col = "match"
)
```

各引数の意味は次のとおりです。

| 引数           | 説明                           |
| ------------ | ---------------------------- |
| `data`       | 判定対象となるデータフレーム               |
| `condition`  | 各行に対して評価する論理式                |
| `result_col` | 判定結果を格納する列名。デフォルトは `"match"` |

`condition` には、データフレーム内の列名を直接使用できます。`data$Q1` のような形式で指定する必要はありません。

例えば、次のデータを使用します。

```
library(Satisficing)

df <- data.frame(
  ID = 1:5,
  Q1 = c(1, 1, 2, 1, 2),
  Q2 = c(4, 2, 4, NA, NA)
)

result <- matching(
  df,
  Q1 == 1 & Q2 >= 3
)

print(result)
```

結果は次のようになります。

| ID | Q1 | Q2 | match |
| -- | -- | -- | ----- |
| 1  | 1  | 4  | 1     |
| 2  | 1  | 2  | 0     |
| 3  | 2  | 4  | 0     |
| 4  | 1  | NA | NA    |
| 5  | 2  | NA | 0     |

`matching()` は元のデータフレームに判定結果の列を追加して返します。元の行順や回答値は変更しません。

## 4. 複数条件の指定

`matching()` では、Rの比較演算子と論理演算子を組み合わせて、複雑な条件を定義できます。

代表的な演算子は次のとおりです。

| 演算子    | 意味            | 使用例                  |
| ------ | ------------- | -------------------- |
| `==`   | 等しい           | `Q1 == 3`            |
| `!=`   | 等しくない         | `Q1 != 3`            |
| `>`    | より大きい         | `Q1 > 3`             |
| `>=`   | 以上            | `Q1 >= 3`            |
| `<`    | より小さい         | `Q1 < 3`             |
| `<=`   | 以下            | `Q1 <= 3`            |
| `&`    | かつ（AND）       | `Q1 == 1 & Q2 == 5`  |
| `\|`   | または（OR）       | `Q1 == 1 \| Q2 == 5` |
| `!`    | 否定（NOT）       | `!(Q1 == 3)`         |
| `%in%` | 指定した値の集合に含まれる | `Q1 %in% c(1, 2)`    |

### 4.1 AND条件

複数の条件をすべて満たす回答者を抽出する場合には、`&` を使用します。

```
matching(
  df,
  Q1 == 1 & Q2 >= 3
)
```

### 4.2 OR条件

いずれかの条件を満たす回答者を抽出する場合には、`|` を使用します。

```
matching(
  df,
  Q1 == 1 | Q2 >= 3
)
```

### 4.3 複合条件

括弧を用いて、AND条件とOR条件を組み合わせることもできます。

```
matching(
  df,
  (Q1 == 1 & Q2 >= 3) |
    (Q1 == 2 & Q2 <= 2)
)
```

この場合、2つの条件群のいずれかを満たす回答者に1が付与されます。

論理式が複雑になる場合には、括弧を使用して評価の順序を明示することを推奨します。

## 5. 調査回答の論理的矛盾の検出

`matching()` の主な応用の一つは、質問項目間の論理的整合性の点検です。

例えば、以下の2項目があるとします。

- Q1：過去1か月に飲酒しましたか（0＝いいえ、1＝はい）
- Q2：過去1か月の飲酒日数（0～30日）

Q1で「いいえ」と回答しているにもかかわらず、Q2で1日以上と回答している場合は、回答内容に不整合があります。

```
df <- data.frame(
  ID = 1:5,
  Q1 = c(0, 1, 0, 1, 0),
  Q2 = c(0, 5, 3, 10, NA)
)

result <- matching(
  df,
  Q1 == 0 & Q2 > 0,
  result_col = "inconsistency"
)
```

| ID | Q1 | Q2 | inconsistency |
| -- | -- | -- | ------------- |
| 1  | 0  | 0  | 0             |
| 2  | 1  | 5  | 0             |
| 3  | 0  | 3  | 1             |
| 4  | 1  | 10 | 0             |
| 5  | 0  | NA | NA            |

回答者3は、飲酒経験がないと回答しながら飲酒日数を3日と報告しているため、指定した条件に一致します。

ただし、このような回答の不整合が必ずしも不注意回答を意味するとは限りません。質問の理解、記憶違い、回答の修正漏れ、入力ミス、質問文の解釈など、さまざまな原因が考えられます。

また、分岐設問によってQ2が本来提示されない場合には、その欠測は回答の矛盾ではありません。調査票の分岐条件を確認したうえで論理式を設定する必要があります。

## 6. 欠測値の取り扱い

`matching()` は、Rの論理式をそのまま評価します。そのため、欠測値を含む場合の結果は、指定した論理式によって異なります。

例えば、

```
Q1 == 1 & Q2 == 5
```

という条件では、Q1が1でQ2が欠測の場合、結果は `NA` になります。

一方、Q1が2であれば、Q2が欠測していても結果は `FALSE` です。

欠測を明示的に条件へ組み込む場合には、`is.na()` を使用できます。

```
matching(
  df,
  Q1 == 0 & is.na(Q2),
  result_col = "missing_pattern"
)
```

これは、Q1が0でQ2が欠測している回答者を検出します。

また、欠測のある回答者を判定不能にせず、条件不成立として扱いたい場合は、次のように指定できます。

```
matching(
  df,
  !is.na(Q1) & !is.na(Q2) &
    Q1 == 0 & Q2 > 0
)
```

ただし、この処理では欠測を含む回答者が0と判定されます。

**欠測により判定できない場合と、条件が成立しない場合を区別することが重要です。** 欠測を0として扱うべきかどうかは、分析目的に応じて判断してください。

## 7. 結果の集計と複数条件の組合せ

判定結果は、通常のRの処理で集計できます。

```
table(result$inconsistency, useNA = "ifany")
```

判定可能な回答者のうち、条件に一致した割合は次のように計算できます。

```
mean(result$inconsistency, na.rm = TRUE)
```

複数の異なる条件について判定する場合は、`matching()` を繰り返し使用できます。

```
result <- matching(
  df,
  Q1 == 0 & Q2 > 0,
  result_col = "rule1"
)

result <- matching(
  result,
  Q1 == 1 & Q2 == 0,
  result_col = "rule2"
)
```

これにより、各回答者について異なる論理条件への一致を別々の列に記録できます。

ただし、上の例では `rule1` と `rule2` の両方が、必ずしも不注意回答を表すわけではありません。各条件が何を意味するかを、調査内容に基づいて定義する必要があります。

## 8. 解釈上の注意点

### 8.1 条件の妥当性は利用者に依存する

`matching()` は汎用的な論理条件判定関数です。条件の妥当性を統計的・理論的に評価する機能はありません。

論理条件によって抽出された回答者を不注意回答者とみなす場合には、条件設定の根拠を示す必要があります。

### 8.2 論理的矛盾と統計的な異常を区別する

例えば「飲酒していない」と「飲酒日数が3日」という回答の組合せは、設問の意味が明確であれば論理的な不整合として扱えます。

一方、複数の設問で異なる回答をしたこと自体は、必ずしも論理的矛盾ではありません。

同じ `matching()` で抽出できる場合でも、両者の解釈は異なります。

### 8.3 データクリーニングと回答者の除外を区別する

条件に一致した回答者を直ちに除外するのではなく、まずデータの点検対象として扱うことが考えられます。

特に質問紙調査では、データ入力、設問分岐、欠測の発生過程なども確認する必要があります。

## 9. 研究での利用方法

`matching()` は、不注意回答を測定する固有の統計指標ではなく、利用者が定義した条件による回答パターンの検出を支援する関数です。

そのため、論文では単に「`matching()` を使用して不注意回答を検出した」と記載するだけでは、分析手続きを十分に説明したことにはなりません。

具体的にどの変数を使用し、どのような条件で判定したかを明記する必要があります。

例えば、飲酒に関する設問間の矛盾を検出した場合は、次のように記載できます。

> 回答の論理的整合性を確認するため、過去1か月の飲酒経験が「なし」であるにもかかわらず、飲酒日数が1日以上と報告されている回答を不整合として定義した。該当する回答は、RパッケージSatisficingの `matching()` 関数を用いて抽出した。

このように、判定条件と使用した関数を併記することで、分析手続きの再現性を確保できます。

## 10. 参考文献

`matching()` は一般的な論理条件評価を実行する関数であり、特定の統計モデルや独自の測定理論に基づくものではありません。そのため、関数のアルゴリズム自体に固有の学術文献は必要ありません。

ただし、論理的な回答の不整合を回答品質の指標として利用する場合には、次の文献が関連します。

Meade, A. W., & Craig, S. B. (2012). Identifying careless responses in survey data. *Psychological Methods, 17*(3), 437–455. [https://doi.org/10.1037/a0028085](https://doi.org/10.1037/a0028085)

この文献は、調査における不注意回答を検出する複数の方法を検討した研究です。ただし、`matching()` のアルゴリズム自体を提案した文献ではありません。

この関数の説明では、`stline()` や `longstring()` のような既存の測定指標と異なり、利用者が設定した条件が、そのまま判定基準になることを中心に据えています。

また、`matching()` はRの論理演算の結果を整数に変換する関数なので、欠測値を含むAND・OR条件の挙動について説明することが、利用者にとって特に重要だと考えます。
