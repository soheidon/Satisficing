# Satisficing v0.3.0 — 実装計画

## ステータス

**Plan Review: Approved**

実装担当はこの計画の公開契約・検証ゲート・許可範囲を守る。計画外の統計仕様変更や互換性差が見つかった場合は変更を止めて報告する。

## 目的

Satisficing 0.2.0を基準に、Kim et al. (2019) が扱う5つのstraightlining測度を誤った同一視なく提供する。新規公開関数 `mrp()`、`mir()`、`spv()` を実装し、既存 `stline()` と `irv()` は変更せず、対応する定義との一致範囲と欠測差を検証・説明する。回答者を自動判定・除外する機能は追加しない。

本計画はユーザー案を精査し、次の既存契約を前提とする。

- `stline()` は各行で2件以上の非欠測値がすべて同一なら `1L`。一部欠測があっても残る値がすべて同一なら1となる。
- `irv()` は各行の項目回答値そのものの標準偏差を計算し、`na.rm=TRUE` が既定。したがって標準的な数値データではKimのStandard Deviation of Batteryに対応する。`irv()` の名称・引数・返り値・欠測仕様は変更しない。
- `longstring()` は項目順の連続ランを測る。MRP/MIR/SPVの頻度・全組合せ測度とは別の情報を持つ。

## 方法論上の定義

参照論文は Kim, Y., Dykema, J., Stevenson, J., Black, P., & Moberg, D. P. (2019), DOI `10.1177/0894439317752406`。数式・用語の最終照合は、論文の利用可能な本文と、比較実装の固定スナップショットを使う。参照実装は `mweylandt/straightliner` の `main` 先端を調査時点で固定した commit `2873384c8bc54aec48abb54e9543c408723fbe0a` とする。これは比較・検証だけに使い、ソースコードをコピーせず、Satisficingの依存に加えない。固定commitの取得・ハッシュを記録する。

### Kimの5測度との対応

|測度|Satisficing API|互換性の扱い|
|---|---|---|
|Simple nondifferentiation|`stline()`|既存APIを維持。完全回答例で一致確認し、欠測時の「全項目同一」と「観測回答が同一」の差を明記|
|Mean root of pairs|`mrp()`|今回追加。行ごとの未標準化値と標本内正規化値を検証|
|Maximum identical rating|`mir()`|今回追加|
|Standard deviation of battery|`irv()`|既存実装を維持。回答値の行内SDとの一致を確認|
|Scale point variation|`spv()`|今回追加|

### 指標の数式

有効回答集合を (A_i)、有効数を (n_i) とする。

- MRP未標準化値: (T_i = {2\over n_i(n_i-1)}\sum_{j<k,\ j,k\in A_i}\sqrt{|x_{ij}-x_{ik}|})。この式は有効な全ペア平均。正規化は標本中の有効な (T_i) の最小・最大を用い、`MRP_i = (max(T)-T_i)/(max(T)-min(T))` とする。高値が相対的に低分化を表す。
- MIR: `max(category count) / n_i`。
- SPV: `1 - sum_c(p_ic^2)`。(p_{ic}) は有効回答中のカテゴリー割合。有効回答のみを使い、欠測をカテゴリーに数えない。理論上の最大値は回答可能カテゴリー数にも依存するため、観測SPVの最大を一律1と説明しない。

MRP正規化は標本依存。(T_i) が計算可能な行が1人だけ、またはすべて同じ値なら、当該行の正規化値は `NA_real_` とする。未標準化 (T_i) は公開結果列に追加しない。比較用テストで内部計算を検証する。

## 公開API契約

新規関数の形式引数:

```r
mrp(data, columns, result_column_name = "mrp")
mir(data, columns, result_column_name = "mir")
spv(data, columns, result_column_name = "spv")
```

- `data`: data.frame。
- `columns`: 2個以上の重複しない既存列名を持つ文字ベクトル。列番号指定は導入しない。
- `result_column_name`: 長さ1の空でない文字列。既存列名と衝突したらエラー。
- 戻り値: 全入力列を保持し、行順・行数を変えず、末尾に数値型の指標列を追加したdata.frame。入力の値やクラスを変更しない。
- 全列名の重複、入力がdata.frameでない、列指定の型/長さ/重複/存在不備、結果列名不正は明示的エラー。
- 各指標は有効回答が2項目未満なら `NA_real_`。全欠測行もNA。0行data.frameは0長の数値列を追加する。
- `Inf`、`-Inf`、`NaN` は有効回答として扱わず、選択列に存在すれば入力エラーとする。通常の `NA` は上記欠測仕様に従う。
- 文字列から数値への暗黙変換は禁止。
- MRPはinteger/double列のみ許容し、factor/logical/characterをエラーにする。中間値が非有限になって定義値を算出できない極端な数値入力は、非有限値を返さず明示エラーにする。
- MIR/SPVは選択列すべてnumeric、またはすべてfactorの場合に許容。numericでは同値の数値を同カテゴリーとし、factorでは内部整数コードでなく表示レベル文字列でカテゴリーを比較する。numericとfactorの混在、character、その他のクラスはエラー。
- 標準的な欠測なし数値入力では、参照実装のMIR/SPV/MRPと数値許容誤差内で一致する。factor、欠測、定数標本、正規化不能条件の差はこのAPI契約を優先し、テスト・文書に記録する。

## 既存APIとの境界

`stline()`、`irv()`、`matching()`、`rawnn()`、carelessから統合した7関数、両データの値・クラス、既存ライセンス表示は変更しない。既存関数と既存テストのdiffはゼロ。既存 `irv()` の動作をKim測度に合わせて変えることは禁止。NEWS/READMEでは5測度の対応を説明し、`stline()`の欠測意味と `irv()` が個人内の行SDを返す既存仕様を過大に主張しない。

## 参照比較・ライセンス

`straightliner` のライセンスはGPL-3.0である。コード・文書・データをコピーしない。固定commitを別の隔離ライブラリに用意し、比較値を生成するだけとする。`straightliner` はSuggests/Imports/Dependsに追加せず、通常のテスト・実行時に要求しない。比較fixtureは固定値として保存し、生成元commit・入力・列順・欠測条件を記録する。比較用パッケージが取得不能なら導入せず、外部比較ゲート未完として停止する。

README.mdとREADME-ja.mdにKim論文の完全な参考文献とDOIを追加する。3関数のRoxygenヘルプに定義、戻り方向、標本依存性、欠測、型制約、例、Kim et al.引用を記す。`NEWS.md` にv0.3.0機能・既存API維持・仕様差を記録する。パッケージ全体の `GPL (>= 2)` とcareless MIT帰属ファイルは維持する。

## テスト計画

1. 手計算fixture: (x=(3,3,4,4)) について未標準化MRP (4/6)、MIR (1/2)、SPV (1/2) を確認。MRPの標本正規化は複数行fixtureで方向・範囲・定数標本を確認。
2. BFI-35相当の35項目・5件法で完全同一、3/4を20/15回、交互配列、3を30回、均等使用、一部欠測、全欠測、1有効回答を作り、計算を確認。
3. 同じ頻度を持つ並べ替えデータでMIR/SPV/MRPが一致することを確認。longstringは順序に応じ変わり得ることを示す。行順の入れ替えは結果行にも同じ順で反映されることを確認。
4. factorはラベルに基づき計算し、別の内部integer codeによる誤った一致がないことを確認。MRP factor拒否、数値factor混在、logical/character、重複列名、重複選択、不在列、既存結果列、NaN/Inf、空行をテスト。
5. 固定straightliner commitのoracle値と通常の数値・完全データ条件で比較。欠測、factor、正規化不能条件では差を別テストで期待し、差の理由を記録する。runtime依存なしを確認。
6. `stline()`は完全データでKimのsimple nondiffとの行別一致を確認し、部分欠測は現行仕様による差を明示。`irv()`は欠測なし数値データで行別 `stats::sd` と一致することを確認。両者の既存テストも維持する。
7. v0.2.0の全既存テストを維持・実行する。結果比較は `expect_equal(..., tolerance=1e-10)` を原則とし、必要な場合のみ根拠と数値スケールを記録する。

### 1. MRP論文式fixtureの具体値とテスト箇所

- **テスト箇所**:
  - `tests/testthat/test-mrp.R`（L1–21）
  - `tests/testthat/test-kim-compatibility.R`（L127–176）
- **数式**:
  Kim et al. (2019, p. 217) に従い、各行の有効回答集合 $A_i$（サイズ $n_i \ge 2$）について未標準化値 $T_i$ を算出:
  $$T_i = \frac{2}{n_i(n_i - 1)} \sum_{j < k,\ j,k \in A_i} \sqrt{|x_{ij} - x_{ik}|}$$
  標本内正規化:
  $$\text{MRP}_i = \frac{\max(T) - T_i}{\max(T) - \min(T)}$$
  高値が低分化（ストレートライニング傾向の強さ）を表す。
- **手計算検証具体値**:
  - 行1: $x = (3, 3, 4, 4)$
    全ペア6組の平方根差: $|3-3|=0, |3-4|=1, |3-4|=1, |3-4|=1, |3-4|=1, |4-4|=0$。
    合計 $= 4$、ペア数 $= 6 \implies T_1 = 4/6 = 2/3$。
  - 行2: $x = (1, 1, 1, 1)$
    全ペア差 $= 0 \implies T_2 = 0$。
  - 行3: $x = (1, 1, 1, 2)$
    全ペア6組の平方根差: $0, 0, 1, 0, 1, 1$。
    合計 $= 3$、ペア数 $= 6 \implies T_3 = 3/6 = 0.5$。
  - 標本内正規化: $\min(T) = 0, \max(T) = 2/3$。
    - 行1: $(2/3 - 2/3) / (2/3 - 0) = 0.0$
    - 行2: $(2/3 - 0) / (2/3 - 0) = 1.0$（完全ストレートライン）
    - 行3: $(2/3 - 0.5) / (2/3 - 0) = (1/6) / (2/3) = 0.25$
  - 列順不変性: 列の並べ替え（`q4, q1, q3, q2`）に対して結果が完全に同一。
  - 定数標本: 全回答者が同一の $T$ 値を持つ場合、正規化分母が0になるため `NA_real_` を返却。

#### 6. 欠測処理と仕様差異 (`nondiff` vs `stline`)
